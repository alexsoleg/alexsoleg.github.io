  1. arXiv
    Machine Learning Multiscale Interactions
    Àlex Solé, Sergio Suárez-Dou, Albert Mosella-Montoro, Silvia Gómez-Coca, Eliseo Ruiz, and 2 more authors

  2. NPJCM
    PRISM: periodic representation with multiscale and similarity graph modelling for enhanced crystal structure property prediction
    Àlex Solé, Albert Mosella-Montoro, Joan Cardona, Daniel Aravena, Silvia Gómez-Coca, and 2 more authors
    npj Computational Materials, 2026
    Abs DOI arXiv Bib HTML

    PRISM is a graph neural network framework for crystal property prediction. It combines periodic feature encoding with multiscale graph experts so the model can represent local chemistry and longer-range crystal structure in the same prediction pipeline.

  3. arXiv
    UNATE: UNsupervised ATomic Embedding for crystal structures property prediction
    Laura Solà-Garcia, Àlex Solé, and Javier Ruiz-Hidalgo
    arXiv preprint arXiv:2605.25866, 2026
    Abs arXiv Bib HTML

    UNATE learns atomic embeddings from unlabeled crystal structures using denoising and contrastive learning. The learned embeddings are then used for crystal property prediction, especially when labeled data is limited.

2025

  1. DD
    A Cartesian encoding graph neural network for crystal structure property prediction: application to thermal ellipsoid estimation
    Àlex Solé, Albert Mosella-Montoro, Joan Cardona, Silvia Gómez-Coca, Daniel Aravena, and 2 more authors
    Digital Discovery, 2025
    Abs DOI arXiv Bib HTML

    CartNet predicts crystal properties by encoding atomic geometry with respect to Cartesian axes and crystal temperature. The first application estimates anisotropic displacement parameters, which are used to describe thermal ellipsoids in crystal structures.

  2. CS
    Exploring hyperfine coupling in molecular qubits
    Joan Cardona, Àlex Solé, Pablo Mella, Daniel Aravena, Javier Ruiz-Hidalgo, and 2 more authors
    Chemical Science, 2025
    Abs DOI Bib HTML

    This paper studies hyperfine coupling in transition-metal molecular qubits with density functional methods. The analysis separates dipolar, isotropic, and spin-orbit contributions to show how molecular structure can tune qubit-relevant properties.

  3. IICMLCN
    Leveraging Quantum Machine Learning for Intrusion Detection in Software-Defined Networks
    Joan Lo Anguera, José Antonio Lázaro, Javier Ruiz-Hidalgo, Àlex Solé, Josep Ramon Casas, and 2 more authors
    In 2025 IEEE International Conference on Machine Learning for Communication and Networking (ICMLCN), 2025
    Abs DOI Bib HTML

    This conference paper compares quantum and classical machine learning models for intrusion detection in software-defined networks using the UNR-IDD dataset. The study reports higher accuracy for the tested hybrid quantum neural network and quantum support vector machine settings than their classical counterparts.
