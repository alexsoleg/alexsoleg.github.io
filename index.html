About my work

I am a PhD candidate at the Image Processing Group at Universitat Politècnica de Catalunya (UPC), supervised by Javier Ruiz-Hidalgo and Eliseo Ruiz. I develop graph neural networks and self-supervised learning methods that encode geometry, chemistry, and periodic structure directly.

My research spans atomic representations, crystal property prediction, thermal motion, and multiscale machine-learning force fields. Before the PhD, I worked on computer vision and remote sensing at Vicomtech, TU Delft, and Istituto Italiano di Tecnologia.

  1. arXiv
    Machine Learning Multiscale Interactions
    Àlex Solé, Sergio Suárez-Dou, Albert Mosella-Montoro, Silvia Gómez-Coca, Eliseo Ruiz, and
    arXiv preprint arXiv:2605.25710, 2026
    arXiv HTML

    MuSE is a hierarchical model for machine learning force fields. It pools atomistic systems into coarse nodes, then lets existing force-field modules model interactions across molecular and material length scales.

  2. NPJCM
    PRISM: periodic representation with multiscale and similarity graph modelling for enhanced crystal structure property prediction
    Àlex Solé, Albert Mosella-Montoro, Joan Cardona, Daniel Aravena, Silvia Gómez-Coca, and
    npj Computational Materials, 2026
    DOI arXiv HTML

    PRISM is a graph neural network framework for crystal property prediction. It combines periodic feature encoding with multiscale graph experts so the model can represent local chemistry and longer-range crystal structure in the same prediction pipeline.

  3. DD
    A Cartesian encoding graph neural network for crystal structure property prediction: application to thermal ellipsoid estimation
    Àlex Solé, Albert Mosella-Montoro, Joan Cardona, Silvia Gómez-Coca, Daniel Aravena, and
    Digital Discovery, 2025
    DOI arXiv HTML

    CartNet predicts crystal properties by encoding atomic geometry with respect to Cartesian axes and crystal temperature. The first application estimates anisotropic displacement parameters, which are used to describe thermal ellipsoids in crystal structures.

  4. IJAEOG
    A learning approach for river debris detection
    Àlex Solé, Leonardo Scandolo, and Elmar Eisemann
    International Journal of Applied Earth Observation and Geoinformation, 2022
    DOI HTML

    This work uses Sentinel-2 satellite imagery and segmentation models to detect floating debris in rivers. It includes a dataset of candidate debris regions and compares deep learning approaches for multispectral remote sensing data.
